# Holberton School: Higher-Level Programming - Python

This repository contains the foundational and advanced Python projects developed as part of the **ALX / Holberton School Web Stack** curriculum. The journey transitions from basic scripting to complex Object-Oriented Programming (OOP) and system integration.

## 📂 Curated Project Roadmap

Each directory represents a specific milestone in mastering high-level programming:

| Module | Focus Area | Key Concepts Covered |
| :--- | :--- | :--- |
| **0x00** | Hello, World! | Python interpreter, basic printing, and script execution. |
| **0x01** | Control Flow | If/Else statements, loops, and basic function implementation. |
| **0x02** | Import & Modules | Understanding `__name__`, importing functions, and scope. |
| **0x03** | Data Structures | Efficient use of Lists and Tuples in Python. |
| **0x04** | More Data Structures | Sets, Dictionaries, and functional tools (`lambda`, `map`, `filter`). |
| **0x05** | Exceptions | Robust error handling using `try`, `except`, `finally`. |
| **0x06** | Classes & Objects | Introduction to OOP: attributes, methods, and `__init__`. |
| **0x07** | TDD | Unit testing using `doctest` and ensuring code reliability. |
| **0x08** | More OOP | Private vs Public attributes, properties (`@property`), and `__str__`. |
| **0x0A** | Inheritance | Base classes, derived classes, and method overriding. |
| **0x0B** | Input/Output | Reading/writing files and serializing data with JSON. |
| **0x0C** | Classes & Objects | Advanced OOP logic and class management. |

## 💡 Core Competencies Developed

### Object-Oriented Programming (OOP)
Building modular and reusable code through **Encapsulation** (private attributes), **Inheritance**, and **Polymorphism**. Understanding the difference between class and instance attributes.

### Test-Driven Development (TDD)
Implementing the "Red-Green-Refactor" cycle. Writing comprehensive unit tests to catch edge cases before they hit production.

### Memory & Object Management
Gaining a deep understanding of how Python treats everything as an object, the difference between mutable and immutable types, and how variables point to memory addresses.

## 📋 Coding Standards

* All files are executable and start with `#!/usr/bin/env python3`.
* No global variables are used (where applicable).
* Code is verified against `pycodestyle` to ensure professional formatting.
* Functions are kept concise and modular to follow the **Single Responsibility Principle**.
